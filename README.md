# 🏜️ Endless Runner – Desert Temple

## 🎮 Project Overview

**Endless Runner – Desert Temple** is a 3D endless running game developed using Unity and C#. The game takes place in a desert-themed ancient temple environment where the player runs continuously, avoids obstacles, collects rewards, and tries to achieve the highest possible score.

The game provides an adventurous experience with different environments, challenging obstacles, collectible items, and power-ups.

## 🎯 Objectives

- To develop an interactive 3D endless runner game using Unity.
- To implement smooth player movement and jumping mechanics.
- To create different obstacles and collectible objects.
- To design an ancient desert temple environment.
- To implement scoring, health, and power-up systems.
- To improve player engagement through increasing difficulty.

## ✨ Game Features

### 1. Player Movement
- Three-lane movement system.
- Jumping and sliding mechanics.
- Automatic forward running.
- Female and male character selection.

### 2. Environment Design
The game includes six different environments:

- Temple Entrance
- Sandy Path
- Inner Temple Corridor
- Broken Bridge
- Oasis Ruins
- Sunset Dunes

### 3. Obstacles
Players must avoid different obstacles, including:

- Falling Stone Blocks
- Spikes
- Rolling Boulders
- Moving Walls
- Fire Traps
- Sand Pits
- Swinging Axes
- Collapsing Pillars

### 4. Collectibles and Power-ups

Players can collect coins, gems, ancient artifacts, and special items.

Power-ups include:
- Speed Boost
- Shield
- Magnet
- Invincibility
- Score Multiplier

### 5. Game Interface
- Main Menu
- Character Selection
- Settings
- Score Display
- Health System
- Distance Counter
- Pause Menu
- Game Over Screen
- High Score Display

### 6. Audio
The game includes background music and sound effects managed through C# scripts.

## ⚙️ How to Run the Project

1. Install Unity Hub.
2. Install Unity 2022.3 LTS.
3. Open Unity Hub.
4. Select **Add Project from Disk**.
5. Browse and select the `EndlessRunner_DesertTemple` folder.
6. Allow Unity to import the project files.
7. Open the Desert Temple game scene.
8. Press the Play button to start the game.

If the scene has not been generated, use the Unity menu:

**Tools → Desert Temple → Setup Project**

## 🧩 Game Development Modules

The project is divided into the following modules:

- **Player Module:** Handles player movement, jumping, sliding, and character animations.
- **Track Module:** Creates and recycles track segments.
- **Obstacle Module:** Manages obstacle spawning and collision detection.
- **Collectible Module:** Handles collection items and rewards.
- **Game Manager:** Controls game states, scoring, health, and game progress.
- **UI Module:** Manages menus, HUD, pause, and game-over screens.
- **Audio Module:** Controls background music and sound effects.
